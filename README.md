# Работа с GitHub: репозитории, совместная разработка и CI/CD

Автор: Кожевников Артем Евгеньевич  
Группа: ПИ-4.10-2022 заочное  
Дисциплина: «Обучение пользователей информационных систем»

Учебный сайт содержит 3 лекции, 3 практические работы и итоговый тест на 30 вопросов.
Сквозной пример — собственный репозиторий course-notes. В нём создают первый коммит,
вносят изменение через pull request и проверяют обязательную фразу в GitHub Actions.

За полностью правильный ответ в итоговом тесте начисляется 1 балл.
Оценки зависят от числа баллов.

- 27–30 — «Отлично»
- 23–26 — «Хорошо»
- 18–22 — «Удовлетворительно»
- 0–17 — «Неудовлетворительно».

## Запуск локально

Команды ниже выполняются в стандартном Windows PowerShell 5.1. Нужен Bun 1.4.4.

```powershell
bun install --frozen-lockfile
bun run dev
```

```powershell
bun run build
bun run preview
```

## Материалы

Workflow проверяет наличие точного текста «проверочная фраза» в README.md
с учётом регистра. Учебная проверка
выполняется на Linux-раннере ubuntu-latest на bash. Локальные команды всех
практик рассчитаны на встроенный Windows PowerShell 5.1.

Практики выполняются в собственном публичном репозитории (Public).
